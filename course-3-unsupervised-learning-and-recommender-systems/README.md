# Course 3: Unsupervised Learning, Recommenders and Reinforcement Learning

This folder contains my implementations and programming assignments from Course 3 of the Machine Learning Specialization by DeepLearning.AI and Stanford Online.

The course covers unsupervised learning algorithms, recommendation systems, and reinforcement learning methods.

## Topics Covered

### Unsupervised Learning
- K-means clustering
- Anomaly detection
- Principal Component Analysis (PCA)

### Recommender Systems
- Collaborative filtering
- Neural network based content filtering
- User and item embeddings
- Movie recommendation systems

### Reinforcement Learning
- Markov Decision Processes (MDP)
- Q-learning
- Deep Q-Networks (DQN)
- Experience replay
- Lunar Lander reinforcement learning agent

## Technologies

- Python
- NumPy
- TensorFlow
- Keras
- Jupyter Notebook
