# Course 2: Advanced Learning Algorithms

This folder contains my implementations and practice assignments from Course 2 of the Machine Learning Specialization: **Advanced Learning Algorithms** by DeepLearning.AI and Stanford Online.

The course focuses on neural networks, machine learning development, model evaluation, regularization, and decision tree algorithms.

## Topics Covered

### Neural Networks

- Neural Network Architecture
- Dense Layers
- Forward Propagation
- TensorFlow Sequential Models
- Activation Functions
- Binary Classification with Neural Networks
- Multiclass Classification
- Softmax Regression
- Sparse Categorical Cross-Entropy

### Model Evaluation and Selection

- Training, Cross-Validation, and Test Sets
- Mean Squared Error (MSE)
- Classification Error
- Bias and Variance
- Diagnosing Underfitting and Overfitting
- Model Complexity
- Model Selection using Cross-Validation

### Regularization

- L2 Regularization
- Regularized Neural Networks
- Controlling Model Complexity
- Comparing Training and Cross-Validation Error
- Selecting the Regularization Parameter (Lambda)

### Decision Trees

- Entropy
- Dataset Splitting
- Information Gain
- Selecting the Best Feature for a Split
- Recursive Tree Construction
- Decision Tree Learning

## Assignments

### 01 — Neural Network Binary Classification

Implemented a neural network for binary classification and explored:

- Neural network layers
- Forward propagation
- Activation functions
- TensorFlow / Keras model construction
- Binary predictions

### 02 — Neural Network Multiclass Classification

Implemented neural networks for multiclass classification and explored:

- Multiclass prediction
- Softmax regression
- Sparse categorical cross-entropy
- TensorFlow Sequential models
- Neural network output interpretation

### 03 — Model Evaluation and Regularization

Explored techniques for evaluating machine learning models and improving their ability to generalize to unseen data.

Main tasks included:

- Implementing mean squared error for regression
- Implementing classification error
- Splitting data into training, cross-validation, and test sets
- Comparing training and cross-validation performance
- Diagnosing high bias and high variance
- Exploring model complexity
- Building neural network architectures
- Applying L2 regularization
- Comparing regularized and unregularized models

### 04 — Decision Trees

Implemented core components of a decision tree learning algorithm.

Main tasks included:

- Computing entropy at a node
- Splitting datasets based on binary features
- Computing information gain
- Comparing candidate features
- Selecting the feature with maximum information gain
- Building a decision tree recursively

The assignment helped reinforce how decision trees choose splits and progressively partition data into increasingly homogeneous groups.

## Key Concepts

The exercises in this course developed practical understanding of several important machine learning workflows:

**Input Data → Neural Network → Training → Validation → Model Selection → Regularization → Testing**

and

**Dataset → Entropy → Information Gain → Best Split → Decision Tree**

These assignments helped build an understanding not only of how machine learning algorithms are implemented, but also how their performance can be evaluated and improved.
