### 02. Neural Network for Multiclass Classification

- Implemented the Softmax function with NumPy
- Built a `400 → 25 → 15 → 10` neural network using TensorFlow/Keras
- Applied ReLU activation to hidden layers
- Used linear logits with Sparse Categorical Cross-Entropy
- Trained the network using the Adam optimizer
- Classified handwritten digits from 0 to 9
- Achieved 99.7% training accuracy on 5,000 examples
